# Triage Labels

Usar estas correspondencias al clasificar issues:

| Rol de las skills | Etiqueta de GitHub | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Pendiente de evaluación. |
| `needs-info` | `needs-info` | Falta información para continuar. |
| `ready-for-agent` | `ready-for-agent` | Trabajo especificado y listo para ejecución por un agente, dentro de las autorizaciones vigentes. |
| `ready-for-human` | `ready-for-human` | Requiere intervención humana. |
| `wontfix` | `wontfix` | Se decidió no realizarlo. |

Estas etiquetas pueden convivir con categorías existentes como `bug`, `documentation` o `enhancement`. Conservar las etiquetas ajenas a esta clasificación al actualizar un issue. La etiqueta de preparación no sustituye la autorización para implementar o desplegar.
