## Límites explícitos y criterios pendientes

- La resolución administrativa global multi-tablero (resumen de tableros, reasignación de owner o recuperación y actos administrativos mínimos) corresponde a #19. #17 solo cubre transferencia iniciada por el owner y protección por último miembro; el criterio global de admin permanece pendiente de #19. Un admin global sin rol owner no obtiene acceso al roster privado ni a `remove_board_collaborator_p`.
- Restauración completa, selección explícita de nuevo owner al restaurar y UI de recuperación corresponden a #18. Esta entrega conserva datos y metadatos recuperables por 168 horas; no implementa restore.
- No hay mecanismo de avisos para reingreso en el código actual. La falta de recuperación de rol/asignaciones/identidad de menciones se prueba; notificar a un miembro reingresado queda pendiente para el ticket que implemente el sistema de avisos.
